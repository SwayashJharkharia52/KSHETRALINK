Geocode Setu - Backend Addition

The backend has been added in the backend/ folder.

Setup steps:
1. Install Node.js and PostgreSQL.
2. Open devtrack/backend in a terminal.
3. Copy .env.example to .env and set your PostgreSQL connection values.
4. Create the database and run sql/schema.sql.
5. Run npm install, then npm start.
6. Check http://localhost:4000/api/health.

Note: The backend is included but the frontend has not yet been wired to its API.
See backend/README.md for full details.
